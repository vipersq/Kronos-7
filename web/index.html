Satelity całkowicie niejawne trafiają do „niezidentyfikowanych” bez nazw albo nie ma ich wcale.

      Liczby obok typów pokazują, ile obiektów jest teraz w pamięci. Warstwy STATKI i LOTNICTWO włączasz pod mapą.
      
  
      

      

      
  
      
    
      > ŹRÓDŁA I INTEGRACJE
      
    
      
      
      
        
      UKRAINA · ALARMY PRZECIWLOTNICZE
      
        
      Działa bez klucza (ubilling.net.ua). Darmowy token z alerts.in.ua (formularz na stronie) daje rodzaj zagrożenia i części obwodów.
      
        
        
        
        
      NOTAM · FAA NOTAM API
      
        
      Darmowe konto: api.faa.gov → zarejestruj aplikację → „NOTAM API” → client_id i client_secret.
      
        
        
        
        
        
      „CIEMNE” STATKI · GLOBAL FISHING WATCH
      
        
      Darmowy token do użytku niekomercyjnego: globalfishingwatch.org/our-apis → API Portal → Create token. Wykrycia radarowe (SAR) statków bez AIS, z kilkudniowym opóźnieniem.
      
        
        
      ACLED · ZDARZENIA KONFLIKTOWE
      
        
      Konto myACLED (acleddata.com → Register). Logowanie e-mailem i hasłem konta. Uwaga: konta „Open” z prywatnym adresem (np. Gmail) mogą nie mieć dostępu do API – wtedy KRONOS pokaże to w stanie źródeł.
      
        
        
        
        
      Promieniowanie (Safecast) i graf powiązań statków (OpenSanctions) działają bez klucza.
      
        
      TELEGRAM OSINT
      
        
      Zaznacz kanały do śledzenia (sprawdzone, aktywne). Więcej kanałów = więcej pracy dla AI przy analizie – najpierw przetwarzane są najnowsze wpisy ze źródeł oficjalnych i OSINT.
